\## Project folder structure

\- literature\_review/: Journal, conference papers, books and news articles for literature review

\- quantitative\_analysis/: Survey raw data, analysis python scripts, analysis reports

\- qualitative\_analysis/: Interview transcripts, consent ethics forms, analysis outputs and visualisations

\- drafts\_and\_reports/: Research proposal drafts, conference manuscripts, final reports

\- supplementary\_materials/: Participant information sheets, photos and other media



\## File navigation instruction

All raw source data stored in respective raw sub‑folders; analysis outputs are placed in reports sub‑folders.
